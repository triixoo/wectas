# Wectas

Блокчейн-стартап из Казахстана. Исследуем цифровые паспорта происхождения для небольших производителей фасованной продукции.

- Сайт: https://triixoo.github.io/wectas/
- Паспорта: https://triixoo.github.io/wectas/passport.html
- Исследование: https://triixoo.github.io/wectas/market.html
- Репозиторий: https://github.com/triixoo/wectas

## Запуск и проверки

Статический сайт без установки зависимостей. `npm run dev` открывает сервер http://127.0.0.1:4173. `npm test` проверяет цепочки, изменения, импортируемые схемы и ссылки на паспорта. Изображения, шрифты и библиотека QR-кодов хранятся локально.

## Что работает

Демонстрационные цепочки; создание черновика партии; экспорт и импорт JSON; проверка SHA-256; ссылка с сжатым паспортом в URL-фрагменте; QR-код и его экспорт. Личные данные и закрытые сведения добавлять в ссылки нельзя. Удаленного хранилища, подписей участников и блокчейн-якоря пока нет.

## Исследование и итерации

Первый анализ: [research/MARKET.md](research/MARKET.md). План: [BACKLOG.md](BACKLOG.md). Изменения: [CHANGELOG.md](CHANGELOG.md).

GitHub Pages публикует `dist/` после успешных тестов на main. Pull requests проходят проверки без публикации.

Каждый понедельник около 10:00 Алматы workflow Market watch проверяет шесть первоисточников, сохраняет снимок статуса и создаёт либо обновляет issue для очередной итерации. Publish Wectas запускается после успешного мониторинга и публикует его статус на странице исследования. GitHub может задерживать запуск расписания; в неактивном публичном репозитории расписания могут отключаться — проверяйте Actions.

Мониторинг обнаруживает изменения текста страниц, включая навигацию. Он не подтверждает новые рыночные факты и не разрабатывает функции самостоятельно. Для автономных содержательных изменений нужен агент с проверенным доступом к GitHub; API-ключи в репозиторий не добавлены.

## Бренд и лицензии

`dist/wectas-logo.svg` — масштабируемый знак с W внутри орбит. `dist/wectas-logo.png` — прозрачный вариант, созданный встроенным Imagegen по референсу пользователя. Промпт сохранён в CHANGELOG.md.

Manrope распространяется по SIL OFL, лицензия в `dist/fonts/OFL.txt`. QR Code Generator Kazuhiko Arase 2.0.4 используется по MIT, лицензия в `dist/vendor/qrcode-LICENSE`.

Исходники нового Wectas имеют отдельную историю, не содержащую старый торговый журнал. `.openai/hosting.json` сохранен только как идентификатор прежней публикации Sites.
