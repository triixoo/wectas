# Изменения Wectas

## 2026-10-07 — первая исследовательская итерация

- Сохранено первое исследование рынка с первоисточниками, конкурентами и неподтвержденными гипотезами.
- Стартовый фокус уточнен: небольшие производители фасованной продукции; не замена обязательной маркировки.
- Логотип: связанные зеленые орбиты, W внутри свободного центра; растровый вариант создан встроенным Imagegen, SVG и favicon встроены в проект.
- Подготовлена публикация GitHub Pages с проверкой кода перед выпуском.
- Добавлены создание черновика паспорта, импорт JSON, проверка хешей, сжатая ссылка и QR-код.
- Проверка целостности отделена от неподтвержденного происхождения и будущего блокчейн-якоря.
- Добавлен еженедельный мониторинг шести первоисточников с записью результата на сайт и задачей в GitHub.
- Создание паспорта доступно после загрузки модулей; раннее нажатие не запускает неподготовленную форму.

Промпт логотипа: сохранить три зеленые орбиты образца, добавить одну W целиком внутри центрального отверстия, без касания линий; прозрачный фон, плоский знак, без теней и дополнительного текста.

## 2026-10-07 — пилот без сервера

По запросу владельца реализованы функции без backend:

- Локальная библиотека партий в IndexedDB, поиск и сохранение отдельных версий. Просмотр ссылки не сохраняет паспорт автоматически; сохранение требует действия.
- Формат v2: дополняемые события, роли участников, подписи ECDSA P-256; проверка сохраняет прежние подписи. v1 остаётся доступен для чтения.
- Ключи защищены AES-GCM/PBKDF2-SHA-256 с 600 000 итерациями; экспорт, импорт, разблокировка в текущей вкладке. Сверенные вручную отпечатки отмечаются отдельно.
- Документы хранятся локально; тип и хеш публикуются в событии. Есть скачивание, удаление локальной копии и сверка отдельно полученного файла.
- Зашифрованная резервная копия переносит весь кабинет. Файл проверяется до атомарного восстановления.
- Ссылки передают только разрешённые публичные поля, без дополнительных метаданных импорта. Печатная этикетка; отдельная обработка слишком большого QR. Размер новой версии ограничен 100 КБ в UTF-8, чтобы собственный экспорт можно было импортировать обратно.
- Запрос тестового закрепления и проверка Sepolia через кошелёк. Основная сеть запрещена. Реальная транзакция разработчиком не отправлялась: нет кошелька с тестовым ETH.
- Заявки готовятся для Telegram @kashyyn, контакт явно предоставлен владельцем. Отправку подтверждает клиент; сайт не заявляет о доставке.
- Страница пилота и `docs/PILOT_PLAYBOOK.md`: сценарий продажи, вопросы интервью, согласование объёма и приёмка. Никаких фиктивных клиентов, платежей или отзывов.

Проверки: 19 автоматических тестов, включая подмену подписанных данных с полным пересчётом хеша, неправильные пароли, документы, ссылки и RPC-фикстуры. Chrome: два независимых участника, подписанный обмен, сохранение после перезагрузки, защищённая копия и восстановление в чистом контексте, ошибочные импорты, формы Telegram, блокировка основной сети; четыре страницы на шести ширинах от 320 до 1440 px. Сервер, постоянные ссылки и реальные коммерческие результаты отсутствуют по границам задачи.
